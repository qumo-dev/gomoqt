A MOQ Session is established when a client dials a server (via `moqt.Dialer`) or a server accepts a connection (via `moqt.Handler`). The session manages subscriptions, announcements, fetches, and probes over the underlying QUIC connection.

## Implementation

### `moqt.Session`

```go
type Session struct {
    // contains filtered or unexported fields
}

func (s *Session) Subscribe(ctx context.Context, path BroadcastPath, name TrackName, config *SubscribeConfig) (*TrackReader, error)
func (s *Session) AcceptAnnounce(prefix string) (*AnnouncementReader, error)
func (s *Session) Fetch(req *FetchRequest) (*GroupReader, error)
func (s *Session) TrackInfo(ctx context.Context, path BroadcastPath, name TrackName) (*PublishInfo, error)
func (s *Session) Probe(targetBitrate uint64) (<-chan ProbeResult, error)
func (s *Session) ProbeTargets() <-chan ProbeResult
func (s *Session) Stats() SessionStats
func (s *Session) CloseWithError(code SessionErrorCode, msg string) error
func (s *Session) Context() context.Context
func (s *Session) ConnectionState() ConnectionState
func (s *Session) LocalAddr() net.Addr
func (s *Session) RemoteAddr() net.Addr
```

Outgoing requests such as subscribing to tracks, fetching specific groups, probing bitrate, or discovering available tracks are handled by the session.

## Request path

`Session.RequestPath` returns the session's request path, on either transport binding
and on either side of the session:

```go
func (h *HandlerImpl) ServeMOQ(sess *moqt.Session) {
    path := sess.RequestPath()
    // path == "/live/alice" for a client that dialed
    // moqt://host/live/alice or https://host/live/alice
}
```

The path is resolved by the binding before the session is constructed, so it is
available immediately — you never wait on the peer's SETUP to read it:

- **WebTransport:** the path is the HTTP request's `r.URL.Path`, resolved by the
  HTTP handshake. It is also still available directly on the `*http.Request` in
  your `http.Handler`, which is where you route with `http.ServeMux`.
- **Native QUIC:** native QUIC has no handshake-time request URI, so the client
  conveys the path in its SETUP message, as the mandatory Path parameter. A
  server-side router reads it before constructing the session; a SETUP that omits
  it, or whose path is not rooted at `/`, is rejected.

A path is always rooted at `/` — dialing `moqt://host` or `https://host` with no
path yields `"/"`. `RequestPath` returns `""` only for a session constructed without a
binding-supplied path, which the `Dialer` and `Server` entry points never produce.

<Note>
`Session.RequestPath` is the session's request path, which selects a server-side
endpoint. It is unrelated to `BroadcastPath`, which identifies a broadcast
*within* an established session — which is why the accessor is not called
`Path`: in this package "path" already means `BroadcastPath`.
</Note>

## Connection State

After a session is established, you can retrieve connection metadata via `ConnectionState()`:

```go
    state := sess.ConnectionState()
    fmt.Println("Protocol version:", state.Version) // e.g., "moq-lite-05"
    fmt.Println("TLS state:", state.TLS)
```

The `ConnectionState` struct contains:

| Field     | Type                      | Description                                 |
|-----------|---------------------------|---------------------------------------------|
| `Version` | `string`                  | The negotiated MOQ protocol version (e.g., `"moq-lite-05"`) |
| `TLS`     | `*tls.ConnectionState`     | TLS connection state when available          |

## Connection Statistics

Use `Session.Stats()` to fetch a point-in-time snapshot of the session's observable metrics.

```go
stats := sess.Stats()
fmt.Printf("estimated bitrate=%d bps\n", stats.EstimatedBitrate)
fmt.Printf("rtt=%s\n", stats.RTT)
fmt.Printf("bytes sent=%d\n", stats.BytesSent)
fmt.Printf("bytes received=%d\n", stats.BytesReceived)
```

`SessionStats` includes:

| Field             | Type           | Description |
|------------------|----------------|-------------|
| `EstimatedBitrate` | `uint64`       | Latest measured outbound bitrate from the probe mechanism. Zero until a measurement is available. |
| `RTT`            | `time.Duration`| Smoothed round-trip time from the underlying transport. Zero when unavailable. |
| `BytesSent`      | `uint64`       | Total bytes sent on the underlying connection. Zero when unavailable. |
| `BytesReceived`  | `uint64`       | Total bytes received on the underlying connection. Zero when unavailable. |

## Track Info

`Session.TrackInfo` opens a Track Stream and requests a track's immutable
publisher properties (TRACK_INFO) — priority, ordering preference, max
latency, and the `Timescale` needed to interpret frame timestamps — without
subscribing to it. The returned properties are fixed for the lifetime of the
track and should be cached by the caller.

```go
info, err := sess.TrackInfo(ctx, "/live/alice", "video")
if err != nil {
	// Handle error
}
fmt.Println("Timescale:", info.Timescale)
```

A publisher can customize the properties a subscriber sees in TRACK_INFO by
implementing `TrackInfoProvider` on its `TrackHandler`; see
[Producing a Track](/moq/produce_track#track-info).

The values are zero when the current transport does not expose the corresponding metrics, such as some WebTransport browser sessions.

## Incoming Requests

Incoming requests, such as track subscriptions and discovery broadcasts, are handled internally by the session's `moqt.TrackMux`, not directly by the `moqt.Session` struct. Therefore, there are no dedicated methods for these requests on `moqt.Session`.

## Terminating a Session

To explicitly close a session due to protocol violations, errors, or other reasons, use the `Session.CloseWithError` method. This closes all associated streams.

```go
func (s *Session) CloseWithError(code SessionErrorCode, msg string) error
```

- `code`: Error code (e.g., from built-in codes)
- `msg`: Descriptive message

Prefer reserved error codes for standard reasons. See [Built-in Error Codes](/moq/errors#built-in-error-codes) for details.
