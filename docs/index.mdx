Build live media with MoQ in Go. `gomoqt` is a free and open source implementation of
Media over QUIC, designed so that writing a publisher or a subscriber feels like
writing an HTTP server.

## Why gomoqt

<Columns cols={2}>
  <Card title="Familiar API design" icon="file-code">
    Inspired by Go's `net/http`. Idiomatic and intuitive to write.
  </Card>
  <Card title="Pure Go: fast and lightweight" icon="feather">
    No cgo or native dependencies, so cross-compiling stays easy. Idiomatic
    goroutines, channels and contexts throughout.
  </Card>
  <Card title="MoQ Lite implementation" icon="file-lines">
    Focused on the practical core today, designed to extend tomorrow.
  </Card>
  <Card title="QUIC-agnostic" icon="shuffle">
    Not tied to a specific QUIC library; uses quic-go by default.
  </Card>
  <Card title="MIT licensed" icon="scale-balanced">
    Permissive OSS: use, modify and redistribute for personal or commercial
    projects.
  </Card>
  <Card title="Ready-to-run examples" icon="play">
    Tiny server and client samples take you from learning to validation in
    minutes.
  </Card>
</Columns>
