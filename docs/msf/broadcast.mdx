---
title: "Broadcast"
---

`msf.Broadcast` is an optional helper that integrates an MSF catalog with `moqt.TrackHandler` routing. It manages the catalog snapshot and per-track handlers together, automatically serving the catalog track and dispatching subscriptions to the appropriate handler. Its catalog is valid at all times: every change is validated, and a change that would make it invalid is refused.

## Create a Broadcast

```go
// Example: ExampleNewBroadcast
catalog := msf.Catalog{
    Version: msf.CurrentVersion,
    Tracks: []msf.Track{
        {
            Name: "video", Packaging: msf.PackagingLOC, Role: msf.RoleVideo, IsLive: new(true),
            Codec: "av01.0.08M.10.0.110.09", Bitrate: new(int64(5000000)), Framerate: new(int64(30)),
        },
        {
            Name: "audio", Packaging: msf.PackagingLOC, Role: msf.RoleAudio, IsLive: new(true),
            Codec: "opus", Bitrate: new(int64(32000)), SampleRate: new(int64(48000)), ChannelConfig: "2",
        },
    },
}

broadcast, err := msf.NewBroadcast(catalog)
if err != nil {
    fmt.Println(err)
    return
}
fmt.Println(broadcast.CatalogTrackName(), len(broadcast.Catalog().Tracks))
```

The catalog is validated before the broadcast is created. You can also start with a zero-value `Broadcast` and call `SetCatalog` later.

## Register Tracks

```go
// Example: ExampleBroadcast_RegisterTrack
broadcast, err := msf.NewBroadcast(msf.Catalog{Version: msf.CurrentVersion})
if err != nil {
    fmt.Println(err)
    return
}
serveVideo := moqt.TrackHandlerFunc(func(tw *moqt.TrackWriter) { /* write groups to tw */ })

// Register a track before any track that depends on it.
err = broadcast.RegisterTrack(msf.Track{
    Name: "video", Packaging: msf.PackagingLOC, Role: msf.RoleVideo, IsLive: new(true),
    Codec: "av01.0.08M.10.0.110.09", Bitrate: new(int64(5000000)), Framerate: new(int64(30)),
}, serveVideo)
if err != nil {
    fmt.Println(err)
    return
}
err = broadcast.RegisterTrack(msf.Track{
    Name: "timeline", Packaging: msf.PackagingMediaTimeline, IsLive: new(true),
    Depends: []msf.Dependency{msf.DependsOnTrack("video")},
}, serveVideo)
fmt.Println(err, len(broadcast.Catalog().Tracks))
```

`RegisterTrack` adds a track to the catalog and associates a `moqt.TrackHandler` with it. If a track with the same name already exists, it is replaced. The catalog is validated after the change, so tracks register in dependency order: a track whose `depends` names a track or render group registers after it. To add tracks that reference each other at once, use `SetCatalog`.

The catalog track name (`"catalog"` by default) cannot be used, and track names must be unique across namespaces, since subscriptions are routed by name.

## Remove Tracks

```go
// Example: ExampleBroadcast_RemoveTrack
broadcast, err := msf.NewBroadcast(msf.Catalog{
    Version: msf.CurrentVersion,
    Tracks: []msf.Track{
        {Name: "video", Packaging: msf.PackagingLOC, IsLive: new(true)},
        {Name: "timeline", Packaging: msf.PackagingMediaTimeline, IsLive: new(true),
            Depends: []msf.Dependency{msf.DependsOnTrack("video")}},
    },
})
if err != nil {
    fmt.Println(err)
    return
}

// "timeline" depends on "video", so removing "video" first is refused
// and the catalog stays as it was.
err = broadcast.RemoveTrack("video")
var validationErr *msf.ValidationError
fmt.Println(errors.As(err, &validationErr), len(broadcast.Catalog().Tracks))

fmt.Println(broadcast.RemoveTrack("timeline"), broadcast.RemoveTrack("video"))
fmt.Println(errors.Is(broadcast.RemoveTrack("video"), msf.ErrTrackNotFound))
```

`RemoveTrack` removes the named track and its handler. It refuses a removal that would leave a dangling reference, returning the `*msf.ValidationError` and changing nothing; remove the dependent tracks first. It returns `msf.ErrTrackNotFound` when there is no such track.

## Use as TrackHandler

`msf.Broadcast` implements `moqt.TrackHandler`, so it can be published directly:

```go
mux := moqt.NewTrackMux(0)
mux.Publish(ctx, "/live", broadcast)
```

Subscriptions to the catalog track name are served with the current catalog serialized as JSON. All other subscriptions are routed to the registered per-track handler.

## Update Catalog

```go
err := broadcast.SetCatalog(newCatalog)
```

`SetCatalog` validates and replaces the catalog snapshot atomically. Tracks present in the old catalog but absent in the new one are removed along with their handlers.

## Catalog Track

The catalog is served as a special track (default name: `"catalog"`, `msf.DefaultCatalogTrackName`). A catalog subscription stays open: it receives the current catalog as its first group, then a new group with the whole catalog each time it changes.
